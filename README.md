# Campus Club Portal

Campus Club Portal is a web application I am developing to provide students with a single place to discover college clubs, events, announcements, and other campus activities.

The project is being built step-by-step as a full-stack application using **React, Node.js, Express.js, and MySQL**. I also plan to integrate an **AI-based club recommendation system** to help students find clubs based on their interests.

## 🤖 AI Club Recommendation

One of the planned features is an AI-based recommendation system.

The idea is to use information such as a student's:

* Interests
* Skills
* Preferred activities
* Areas of study

to suggest clubs that may be relevant to them.

For example:

```text
Student Interests
       ↓
Programming + AI + Hackathons
       ↓
Recommendation System
       ↓
Coding Club
AI/ML Club
Robotics Club
```
